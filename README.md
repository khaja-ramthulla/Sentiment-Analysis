# Sentiment Analysis

An advanced sentiment analysis platform that analyzes text and identifies sentiment, emotions, confidence scores, keywords, and sentence-level sentiment insights.

## Features

* Positive, Negative, and Neutral Sentiment Detection
* Confidence Score Analysis
* Emotion Detection
* Keyword Extraction
* Sentence-Level Sentiment Analysis
* Interactive Dashboard
* Responsive User Interface

## Technologies Used

* Python
* Flask
* Scikit-Learn
* NLTK
* YAKE
* TF-IDF Vectorization
* Logistic Regression

## How It Works

The system processes user input using Natural Language Processing techniques and a machine learning classification model to determine sentiment and emotional tone. It also extracts important keywords and analyzes individual sentences for detailed insights.

## Dashboard Analytics

* Sentiment Classification
* Confidence Score
* Emotion Detection
* Word Count
* Reading Time
* Keyword Analysis
* Sentence Breakdown
